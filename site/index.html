Discord 로그

디스코드 웹의 메시지와 입력 중 알림을 기록합니다.

실행

  1. 아래 버튼으로 실행 코드를 복사합니다.
  2. 디스코드 웹에서 F12 → Console을 열고 실행합니다.
  3. 열린 기록 창에서 서버 ID를 입력하고 기록 시작을 누릅니다.

수신 숫자가 늘어나는데 해제가 0이면 기록 창에서 재연결을 누르세요. 디스코드 탭을 새로고침하면 다시 실행해야 합니다.

팝업이 차단됐다고 나올 때
  1. 코드를 실행한 디스코드 탭으로 이동합니다.
  2. 주소창 오른쪽의 팝업 차단 아이콘 (작은 창에 ×)을 누릅니다.
  3. discord.com의 팝업 및 리디렉션 항상 허용 → 완료를 선택합니다.
  4. Console에서 같은 실행 코드를 다시 실행합니다.

아이콘이 없다면 주소창 왼쪽 사이트 설정 → 사이트 설정 → 팝업 및 리디렉션 → 허용. GitHub Pages가 아니라 디스코드 사이트에 허용해야 합니다. 웹사이트가 이 설정을 자동으로 바꿀 수는 없습니다.
